# Mazda CMU CarPlay-HUD Toolkit — Ukrainian

Поворотна навігація з **Apple CarPlay** на **Head-Up Display** для Mazda CMU150 (прошивка 74.00.324) — з правильним індикатором ліміту швидкості в **км/год** для європейського ринку.

**Підходить для:** CX-5 KF, CX-8, CX-9 (2016-2023) та інших з EU-прошивкою тієї ж платформи.

**Переклади:** [English](README.md) · [Español](README.es.md) · [Deutsch](README.de.md) · [Português](README.pt.md)

---

## Що робить цей набір

На основі community-моду [KidMixer/mazda-carplay-hud](https://github.com/KidMixer/mazda-carplay-hud) з двома доповненнями для авто з EU-ринку:

1. **Виправлення km/h** — однорядковий патч у вихідному коді (`displaySpeedUnit = 2` замість `1`, тобто VBS enum `km/h` замість `mph`). Без нього HUD у EU-версії відображає знак `50 км/год` від шима як `≈80 км/год` після конвертації mile→km.
2. **Демон-дзеркало ліміту швидкості** — маленький shell-скрипт, який пасивно слухає штатний потік від `svcjcinavi.so` і копіює *поточне* значення ліміту у власні keep-alive-кадри шима. Без нього шим переписує slot швидкості нулем кожні 500 мс, і значення падає в `---` між оновленнями OEM.

Все інше — біт-у-біт оригінал KidMixer.

---

## Вимоги

- Mazda CMU150, прошивка `74.00.324`, EU-версія (перевірка: `cat /jci/version.ini`)
- USB-флешка (від 1 ГБ, FAT32)
- Комп'ютер з Wi-Fi (macOS, Linux або Windows 10+)
- Wi-Fi hotspot на CMU (з wireless-CarPlay донглом) або робочий root+SSH за інструкцією нижче

## Меню (`toolkit.sh` та `toolkit.bat`)

| # | Дія |
|---|---|
| **1** | **Створити флешку** — форматує USB (FAT32, мітка MZD) з розблокуванням MP3-XSS (кнопка SSH) **і** HUD-патчем (`hud-mod/`). В авто екранне меню пропонує **SSH**, **HUD+** (встановити), **HUD-** (видалити) і **HUD?** (перевірити), тож патч можна встановити без ноутбука. |
| **2** | **Резервна копія CMU** — завантажує через SSH архів усіх файлів, які змінює патч, у `backups/РРРРММДД_ГГХХСС/`. Зробіть це перед встановленням. |
| **3** | **Відкат** — видаляє **всі** HUD-патчі: CarPlay + Android Auto, ilshyma v16 з демоном швидкості, KidMixer і oem-aa-mod. Повертає заводський стан, перезавантажує й перевіряє. |
| **4** | **Встановити HUD-патч (CarPlay + Android Auto)** — один патч для обох телефонів: стрілки й відстань для CarPlay і Android Auto та знак обмеження швидкості зі штатної навігації (потрібна SD-карта навігації). Кожен файл перевіряється за md5. Тулкіт перезавантажує блок, чекає SSH і перевіряє, що всі 4 модулі завантажились. Вихідний код: [mazda-carplay-hud `unified-carplay-aa`](https://github.com/ilshyma/mazda-carplay-hud/tree/unified-carplay-aa). Назва вулиці на європейських HUD не відображається. |
| **A** | **Розширені** — перевірка встановлення, перевірка SSH, діагностика та старіші патчі лише для CarPlay (v16, чистий KidMixer, legacy) з їхніми інструментами. |


### Встановлення HUD-патча з флешки (без ноутбука)

Флешка з пункту 1 також містить патч CarPlay + Android Auto для HUD (`hud-mod/`). В авто відкрийте її як зазвичай: Медіа → USB → торкніться будь-якого mp3. У меню вгорі екрана є три нові кнопки:

- **HUD+** — встановити патч. Натисніть, потім натисніть червону кнопку підтвердження. Блок сам перезавантажиться приблизно через 30 с.
- **HUD-** — видалити, повернення до заводського стану. Підтвердження так само.
- **HUD?** — перевірити, що всі частини активні: CarPlay, Android Auto, навігація/швидкість.

Кожна кнопка завершується повідомленням на екрані. Якщо воно починається з **ERROR** або **CHECK S1** — сфотографуйте його й надішліть. У ньому є код помилки, версія прошивки, регіон і що робити далі. Кожна спроба отримує на флешці власну пронумеровану папку `hud-mod/logs/001_install_<дата>/`: той самий текст (`RESULT.txt`), повний лог (`run.log`) і знімок системи (`system.txt`). Надішліть цю папку разом із фото.

## Перше встановлення

1. Форматуйте флешку, запустіть **опцію 1** для підготовки.
2. Вставте флешку в авто. Media → USB → тапніть будь-який MP3 → чекайте на XSS-меню внизу екрана → тапніть **SSH**. З'являться зелені логи, готово.
3. Підключіть комп'ютер до Wi-Fi CMU (`CMU-XX:XX:...` або `MAZDA-xxx`).
4. Запустіть **опцію 9** для перевірки SSH, потім **опцію 2** для резервної копії.
5. Запустіть **опцію 4** (ilshyma HUD Patch) для встановлення. Дочекайтесь ребуту.
6. На CMU повторіть крок 2 (USB → SSH) щоб знову увімкнути SSH.
7. Тест — запустіть навігацію в CarPlay. Стрілка маневру має з'явитись на HUD; slot ліміту швидкості має показувати поточне OEM-значення (з карти + камери TSR).

## Примітки та обмеження

- Шим працює тільки через `LD_PRELOAD` — оригінальний `blmjcicarplay.so` НЕ змінюється на диску. Read-only rootfs не дає «окирпичити» голову; у крайньому випадку ребут повертає стокову поведінку.
- Демон-дзеркало НЕ надсилає жодних NNG-запитів. Лише слухає штатний потік, що вже транслюється по D-Bus. Поведінка максимально близька до стокової.
- Стрілки рядності (`SetRecommLaneReq`) НЕ реалізовані — Apple не передає дані рядності через iAP2 side-channel; вони існують тільки в CarPlay video stream.
- Кириличні назви вулиць відображаються коректно; український апостроф (`’`) наразі рендериться як `?`, бо OEM-шрифт HUD не має цього гліфа — обмеження OEM.
- Збірка з `-DCARPLAY_VN_NORMALIZE=1` (нормалізація в'єтнамської діакритики). Не заважає кирилиці/латинці.

## Технічні деталі

- Базовий шим: **KidMixer/mazda-carplay-hud v2.0.0** — [source](https://github.com/KidMixer/mazda-carplay-hud), AGPL-3.0.
- Наша єдина зміна в коді: `hud/hud_send.cpp` рядок 561, `displaySpeedUnit` `1 → 2` (VBS enum: `1 = mph`, `2 = km/h`).
- Демон-дзеркало: наш ~60-рядковий shell-скрипт; пасивно слухає виклики `com.jci.vbs.navi.SetHUDDisplayMsgReq` (від НЕ-нашого шима) і пише `<km/h> <unix_ts>` у `/data_persist/splim`. Оновлюється кожні 3 сек, TTL 3600 сек.
- Шим при кожному keep-alive-кадрі читає `/data_persist/splim`; якщо файл свіжий — вставляє значення; якщо пустий/старий — надсилає `0`.

## Що робити, якщо не працює

Якщо SSH не відповідає на порту 36000 — `sshd` на голові було вбито read-only rootfs при завантаженні. Повторіть USB → XSS → SSH.

Якщо HUD пустий після встановлення — перевірте опцією 9, потім SSH-командою `ps | grep sm_svclauncher | grep jciCARPLAY` — процес `L_jciCARPLAY` має бути живим із `LD_PRELOAD` у `/proc/PID/environ`.
